# Changelog

## 0.3.0-alpha.1 — Development Alpha / unpublished

- 1.8.9 Forge 11.15.1.2318向けClient実装を正式Repositoryの統合branchへ整理。
- WPF/.NET 8専用Windows Launcher、Setup/Portable生成、Profile、Mod/Pack、Repair、更新確認を統合。

- 公式WebのFAQ、Download状態、最新公開Alphaの検出・不正URLの拒否を改良。

このバージョンは配布可能な完成版であることを示しません。認証/PLAY/Local WorldのEnd-to-End Gateが未達で、Public Alpha Releaseはまだありません。
