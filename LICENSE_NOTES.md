# Distribution boundary

Ttro Client source is MIT except the attributed Mouse Tweaks source, which retains BSD-3-Clause. See LICENSE, THIRD_PARTY.md and docs/MOUSE_TWEAKS_LICENSE.txt. Copyright notices and full upstream license are included in the JAR and source package.

Distribution contains only Ttro Client code, attributed inventory source, documentation and QA evidence. No Minecraft/Forge/OptiFine/PolyPatcher/MWE binaries or API credentials. A `.mrpack` contains the Ttro Client override and fixed Minecraft 1.8.9 / Forge version references; it does not contain Minecraft game files. The installer/authentication provider must retrieve them from licensed sources.

External downloads are offered with versions, licenses, source URLs and dependency changes before installation. License labels do not mean every candidate is approved for bundling. Performance stack candidate selection is separate from license review and real compatibility testing.
